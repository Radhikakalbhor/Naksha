# Naksha

> AI-Powered Geospatial Intelligence Platform

**Naksha** is an AI-powered platform that automatically converts drone and satellite orthophotos into GIS-ready vector datasets. It is designed to reduce the manual effort involved in digitizing geospatial features by using Artificial Intelligence, Computer Vision, and Geographic Information Systems (GIS).

## Problem Statement

High-resolution drone and satellite imagery is widely used in urban planning, agriculture, forestry, infrastructure development, and environmental monitoring. However, converting these images into structured GIS data still requires extensive manual digitization, making the process slow, expensive, and difficult to scale.

Naksha aims to automate this entire workflow by extracting GIS-ready information directly from orthophotos.

## Key Features (Planned)

- Building Footprint Extraction
- Road Detection and Centerline Extraction
- Farm Boundary Delineation
- Tree Detection and Counting
- Water Body Extraction
- Land Use / Land Cover (LULC) Classification
- Confidence Scoring
- GIS Export (GeoJSON, Shapefile, GeoPackage, FileGDB)

## Technology Stack (Planned)

- Frontend: React + TypeScript
- Backend: FastAPI
- AI Framework: PyTorch
- GIS Processing: GDAL, Rasterio, GeoPandas, Shapely
- Database: PostgreSQL + PostGIS
- Storage: MinIO / S3
- Task Queue: Celery + Redis
